## 3. 推荐值

**`degraded_threshold = 0.15`**

- accuracy = 0.3308，macro-F1 = 0.3398，OTHER 率 = 0.1654
- 约束：OTHER 率 ≤ 0.35（避免「全部转澄清」），在此约束下取 macro-F1 最大

## 4. 重要局限（必须读）

1. **离线集上 LLM 恒失败**，权重只在 emb/pat 间归一化，分数分布被压缩；
   一旦 LLM 上线，`_fuse` 走正常权重（0.7/0.2/0.1），分数尺度完全不同，**该阈值需重新标定**。
2. 数据集为人工构造 133 条，非真实工单分布。
3. 本标定只优化「意图分类」单一目标，未考虑业务代价（误分类 vs 多问一句的体验成本）。
