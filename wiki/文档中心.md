# OpsMind Wiki 文档中心

OpsMind 面向企业 IT 服务台与运维协同，支持 19 类意图识别、主辅 Agent 路由、运维 RAG、三级记忆、动态 Skills、在线监控和端到端评测。服务台、事件响应、访问权限 SOP 会按 Agent 类型和关键词注入 system prompt；未接入真实业务系统时，Agent 只整理诊断或交接信息，不伪造工单、监控、IAM 与审批结果。
